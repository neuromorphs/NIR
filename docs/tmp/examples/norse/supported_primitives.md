### Supported Primitives in Norse

This library supports conversion of the following nodes to NIR:
- Conv1d
- Conv2d
- Flatten
- Affine
- Linear
- CubaLI
- CubaLIF
- IF
- LI
- LIF
- AvgPool2d

This library supports conversion of the following nodes from NIR:
- Conv2d
- Flatten
- Affine
- CubaLIF
- IF
- LI
- LIF
- SumPool2d
